# 摄像头服务部署与验证

## 现在的功能

- App 远程抓拍一张画面，并显示在“摄像头与服药记录”页面。
- App 可下发 20 秒服药录像任务。
- 香橙派在本机录像、生成缩略图、上传后端，不上传音频。
- 家庭成员 App 可在权限范围内查看缩略图、播放录像、标记“确认已服药”或“不是服药”。
- 后端只在设备活跃时发放任务，素材必须经过登录鉴权，不能通过公网静态目录直接访问。

App 现在支持约 1 fps 的近实时预览：App 开启预览后，香橙派约每 0.65 秒抓一帧并上传，App 约每 0.7 秒刷新。它不是 WebRTC 视频直播，但足够用于取景和人脸注册；离开页面会自动停止。

## 数据流

```text
App -> 后端：创建 camera_snapshot / intake_record 命令
香橙派 -> 后端：领取命令
香橙派：抓拍或录像
香橙派 -> 后端：multipart 上传 JPEG/MP4 + 缩略图
后端：按家庭成员权限保存和提供素材
App：查看缩略图、播放、确认状态
```

## 后端配置

在 `backend/.env` 设置：

```env
SMB_DEVICE_AGENT_TOKEN=换成一串强随机值
SMB_DEVICE_CAMERA_DIR=./data/camera_assets
SMB_DEVICE_CAMERA_MAX_UPLOAD_MB=200
```

`SMB_DEVICE_AGENT_TOKEN` 不能继续使用开发默认值。修改后，App 不需要知道此 token；只有香橙派代理需要。

上传目录必须由后端服务账号可写，并应纳入备份与隐私数据清理策略。正式环境建议放在独立数据盘，不要放进源代码仓库。

## 后端接口

家庭账号接口：

```text
GET   /api/v1/hardware-devices/{device_id}/camera/assets
GET   /api/v1/hardware-devices/{device_id}/camera/assets/{asset_id}/file
GET   /api/v1/hardware-devices/{device_id}/camera/assets/{asset_id}/thumbnail
PATCH /api/v1/hardware-devices/{device_id}/camera/assets/{asset_id}/review
POST  /api/v1/hardware-devices/{device_id}/commands
POST  /api/v1/hardware-devices/{device_id}/camera/preview/start
POST  /api/v1/hardware-devices/{device_id}/camera/preview/stop
GET   /api/v1/hardware-devices/{device_id}/camera/preview/status
GET   /api/v1/hardware-devices/{device_id}/camera/preview/frame
GET   /api/v1/hardware-devices/{device_id}/recognition-events
GET   /api/v1/hardware-devices/{device_id}/runtime
```

设备代理接口（必须带 `X-Agent-Token`）：

```text
POST /api/v1/device-agent/camera-assets
GET  /api/v1/device-agent/commands/next
POST /api/v1/device-agent/commands/{command_id}/result
POST /api/v1/device-agent/camera/preview-frame
GET  /api/v1/device-agent/preview/status
POST /api/v1/device-agent/recognition-events
```

支持的摄像头命令：

- `camera_snapshot`：抓拍一张 JPEG。
- `intake_record`：录制 MP4，并生成 JPEG 缩略图。

## 香橙派部署

本机项目目录执行：

```powershell
python hardware\pi\deploy_device_agent.py `
  --host 192.168.49.13 `
  --base-url https://smart-medicine-box.124.156.137.131.nip.io `
  --device-uid orangepi-001 `
  --agent-token 与后端一致的强随机值
```

脚本会复制代理、抓拍、录像和模型脚本，创建 `device-agent.json`，并启用 `smb-device-agent` 服务。已有配置默认不覆盖；需要重置时加 `--force-config`。

如果密码不在 Armbian Imager 的设置文件中，可增加：

```powershell
--password-file C:\path\to\settings.json
```

部署后检查：

```bash
systemctl status smb-device-agent --no-pager
journalctl -u smb-device-agent -n 80 --no-pager
ls -l /dev/video1
```

## App 操作和验收

1. 手机登录家庭账号。
2. 进入“设备管理 -> 智能药箱设备 -> 摄像头抓拍与服药记录”。
3. 点击“抓拍一张画面”，等待设备领取任务并上传。
4. 点击“录制 20 秒服药视频”，录完后点缩略图播放。
5. 点“确认已服药”或“不是服药”。

验收标准：

- [ ] Pi 在线，自动轮询命令成功。
- [ ] 抓拍图能在 App 显示。
- [ ] 录像可播放并显示缩略图。
- [ ] 另一个未绑定家庭账号无法读取素材。
- [ ] 录像无音频。
- [ ] App 确认后状态变为“已确认服药”或“未确认服药”。
- [ ] 录像不会自动生成真实服药记录，避免误报。

## 隐私和安全

- 素材通过带 Bearer Token 的受保护接口读取，不放入公开静态目录。
- 设备代理使用独立 `X-Agent-Token`，与用户 JWT 分离。
- 只允许设备所属老人和已绑定的子女访问。
- 视频默认无音频，避免录下家庭对话。
- 视频只是“疑似服药”的辅助证据，最终由家属或本人确认。
