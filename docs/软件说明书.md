# 智享药箱家庭用药管理系统 V1.0

## 1. 软件简介

“智享药箱家庭用药管理系统”是一套面向老年人及其家属的家庭用药安全管理软件，由 Flutter 移动端和 Python FastAPI 服务端组成。系统支持药品建档、图像识别、说明书解析、用药计划、服药记录、库存及有效期提醒、药物冲突检查、家庭成员协同和语音交互，帮助用户按计划安全用药。

本软件仅提供信息记录、提醒和辅助识别功能，不能替代医生诊断、处方或药师指导。

## 2. 系统架构

系统采用前后端分离架构：

1. **移动应用层**：Flutter/Dart，实现 Android（并兼容 Windows、Web、iOS、macOS 工程）的用户界面、相机、语音、通知和本地状态管理。
2. **服务接口层**：Python 3、FastAPI、Uvicorn，提供 REST API、身份认证、权限校验、业务编排和限流。
3. **业务与数据层**：SQLModel/SQLite，保存用户、家庭关系、药品、提醒、服药日志、设备令牌和审计日志。
4. **智能服务层**：对接智谱视觉/文本模型进行药品图片识别和说明书信息提取；对接 DuerOS 及移动端语音能力实现语音问答。
5. **消息与运维层**：移动推送令牌、后台推送 worker、数据库备份脚本及健康检查接口。

## 3. 登录与注册

用户在移动端输入手机号、密码和角色完成注册。角色分为老人和家属。登录成功后服务端签发 Bearer JWT，客户端通过 `Authorization` 请求头访问受保护接口。

主要接口：

- `POST /api/v1/auth/register`：注册账号；
- `POST /api/v1/auth/login`：登录并取得访问令牌；
- `GET /api/v1/auth/me`：读取当前用户资料（如启用）。

密码在服务端以哈希形式保存，不保存明文密码。令牌过期或无效时接口返回未授权错误，客户端应清除本地会话并要求重新登录。

## 4. 药品录入与识别

用户可手工录入药品名称、类别、厂家、规格、用法用量、注意事项、库存量和有效期，也可调用相机拍摄药盒图片。

图像识别流程如下：移动端上传图片至 `POST /api/v1/ai/recognize-medicine`，服务端调用视觉模型提取药品信息，并返回置信度、来源类型和可编辑字段。置信度低于安全阈值时禁止直接保存，用户必须人工核对。药品记录保存 `information_source` 和 `source_type`，用于追溯数据来源。

药品管理接口包括 `GET/POST/PATCH/DELETE /api/v1/medicines`。删除或修改药品前应确认其关联提醒和服药记录的影响。

## 5. 用药计划与提醒

用户可为药品创建每日、每周或指定时间的提醒，设置剂量、频次、开始/结束日期和启用状态。服务端通过 `POST /api/v1/reminders` 创建计划，通过提醒列表接口查询和维护计划。

移动端根据计划生成本地通知；配置推送服务后，后台 worker 可向已登记设备发送远程提醒。系统还提供库存不足、临期和过期药品告警，相关信息可通过 `GET /api/v1/alerts` 查询。

## 6. 服药记录

用户在提醒到点后确认已服药，或在记录页面手动补录。`POST /api/v1/intake-logs` 写入服药日志，并自动扣减对应库存；`GET /api/v1/logs/today`、`/week` 和历史接口用于查看统计。重复确认会被检测并避免重复记账。

记录包含药品、剂量、时间、备注和所属用户，可供老人和已绑定家属查看。系统保留必要的操作审计信息。

## 7. 家庭成员绑定

老人账号通过 `POST /api/v1/auth/generate-bind-code` 生成具有有效期的绑定码，家属输入绑定码调用 `POST /api/v1/auth/bind-family` 完成绑定。`GET /api/v1/auth/my-family` 返回当前家庭成员关系。

绑定后，家属可在授权范围内查看老人的药品、提醒、服药记录和告警，但不能访问其他家庭的数据。系统通过用户角色、家庭关系和资源所属人进行访问控制。

## 8. AI 与语音功能

- **说明书解析**：`POST /api/v1/ai/parse-instruction` 将用户提供的说明书文本交由文本模型提取用法、剂量和注意事项；
- **药物冲突检查**：`POST /api/v1/conflicts/check` 根据药品组合返回潜在冲突提示；
- **语音交互**：移动端使用语音识别和语音合成进行播报；DuerOS 技能接口支持查询今日用药、确认服药、药品信息、有效期和库存；
- **设备配对**：可生成配对码并绑定 DuerOS/推送设备。

AI 结果属于辅助信息，系统提示用户以药品说明书、医生或药师意见为准。模型无法确认时返回错误或要求人工核验，不伪造药品名称和用法。

## 9. 异常处理和权限说明

服务端统一返回 HTTP 状态码和 `detail` 错误信息：参数错误为 400/422，未登录为 401，无权访问为 403，资源不存在为 404，服务异常为 5xx。客户端应显示可理解的提示，并允许重试或改为手工录入。

系统包含以下安全措施：JWT 身份认证、按家庭关系的数据隔离、请求频率限制、药品操作审计、AI 低置信度拦截和生产环境 HTTPS 要求。API 密钥、JWT 密钥等敏感配置只能通过环境变量或密钥管理服务提供，禁止提交到代码仓库。

相机、麦克风、通知和网络权限仅在对应功能使用时申请。用户可在系统设置中撤销权限；撤销后不影响已保存的手工数据，但图像识别、语音和推送功能可能不可用。

## 10. 运行环境

### 移动端

- Android 设备或模拟器（建议 Android 8.0 及以上）；
- Flutter SDK 3.x，Dart SDK 3.x；
- 相机、麦克风、通知和网络权限；
- 通过 `flutter pub get` 安装依赖，使用 `flutter run` 运行或 `flutter build apk --release` 构建安装包。

### 服务端

- Ubuntu Linux 服务器（推荐 20.04 及以上）或等效 Windows/Linux 环境；
- Python 3.10 及以上；
- SQLite 数据库；
- 安装 `backend/requirements.txt` 中的 FastAPI、Uvicorn、SQLModel 等依赖；
- 使用 `uvicorn app.main:app --host 0.0.0.0 --port 8000` 启动；
- API 文档地址为 `/docs`，健康检查地址为 `/api/v1/health`。

### 配置项

运行前设置数据库连接、JWT 密钥、CORS 来源、AI 模型 API Key、模型名称、DuerOS 用户标识和是否生成演示数据等环境变量。生产环境应关闭演示数据并配置强随机密钥。
