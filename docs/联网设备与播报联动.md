# 联网设备与播报联动

## 已完成的电脑侧内容

- 香橙派常驻代理：HTTP 命令轮询、近实时预览、识别事件上传。
- 后端设备注册、人脸注册任务、命令结果、摄像头素材和识别事件。
- WebSocket 设备通道：`/api/v1/device-agent/ws?device_uid=...`，使用 `X-Agent-Token`。
- HTTP 轮询作为断线和旧客户端兜底。
- 雷达事件、小智状态、SYN6288 状态接收接口。
- 统一播报协调：小智 `listening/speaking` 时取消待播报并产生停止信号。
- 后端返回 GB2312 Base64 播报文本，ESP32 可直接发送 SYN6288。
- ESP32-C3 联网固件源码。
- App 近实时预览、老人人脸注册、最近识别事件、设备运行状态、服药视频播放和确认。

## 数据流

```text
LD2410C -> ESP32-C3 -> 后端 radar_event
香橙派 -> 摄像头 -> 后端 recognition_event
后端 -> 根据家庭成员和人脸模板生成播报
后端 -> App: 运行状态和识别记录
ESP32-C3 -> 后端: 领取 announcement
ESP32-C3 -> SYN6288: GB2312 文本

小智服务 -> 后端 xiaozhi_state
后端 -> 待播报取消 / stop_tts
ESP32-C3 -> 读取 stop_tts_requested_at
ESP32-C3 -> SYN6288 stop frame
```

## 设备代理接口

所有接口校验 `X-Agent-Token`：

```text
POST /api/v1/device-agent/heartbeat
GET  /api/v1/device-agent/commands/next
POST /api/v1/device-agent/commands/{id}/result
POST /api/v1/device-agent/recognition-events
POST /api/v1/device-agent/radar/events
POST /api/v1/device-agent/xiaozhi/state
POST /api/v1/device-agent/syn6288/state
GET  /api/v1/device-agent/runtime
GET  /api/v1/device-agent/announcements/next
GET  /api/v1/device-agent/preview/status
POST /api/v1/device-agent/camera/preview-frame
WS   /api/v1/device-agent/ws?device_uid=orangepi-001
```

WebSocket 客户端连接示例：

```python
import asyncio
import websockets

async def main():
    uri = "wss://smart-medicine-box.124.156.137.131.nip.io/api/v1/device-agent/ws?device_uid=orangepi-001"
    async with websockets.connect(uri, additional_headers={"X-Agent-Token": "设备令牌"}) as ws:
        print(await ws.recv())
        async for message in ws:
            print(message)

asyncio.run(main())
```

## 小智状态回调

香橙派上新增了：

```bash
python3 /home/orangepi/report_xiaozhi_state.py idle
python3 /home/orangepi/report_xiaozhi_state.py listening --event-id xxx
python3 /home/orangepi/report_xiaozhi_state.py speaking --event-id xxx
```

小智服务在对话生命周期变化时调用即可。后端收到 `listening` 或 `speaking` 后：

1. 取消所有 `pending/delivered` 播报。
2. 更新 `stop_tts_requested_at`。
3. 通过 WebSocket 向已连接设备发送 `stop_tts`。

## 播报规则

- 只有已注册人脸且 1.5 米内有人时才生成个人用药播报。
- 未识别人员不播报个人药品信息。
- 同一雷达在场周期内同一成员只生成一次播报。
- 小智忙时最多等待 10 秒，超时丢弃。
- 播报只是提醒，不自动确认服药。

## ESP32-C3 固件

源码：

`hardware/esp32c3/smart_box_node/smart_box_node.ino`

依赖 ArduinoJson 7.x。把 `secrets.h.example` 改名为 `secrets.h` 并填写 WiFi、后端地址、设备标识和设备令牌。

固件每 1 秒读取一次运行状态，每 1.5 秒尝试领取播报，因此小智打断通常会在 1 秒内停止 SYN6288。完整接线见同目录 `README.md`。

## 人脸身份自由设置

App 的“设备管理 -> 智能药箱设备 -> 人脸身份设置”支持把每张已注册人脸设为：

- 老人：选择具体老人，识别后播报该老人的药箱。
- 子女：选择具体子女，识别后播报该子女自己的药箱。
- 陌生人：不播报任何个人用药，只保存识别事件。

后端接口：

`PATCH /api/v1/hardware-devices/{device_id}/faces/{face_id}`

请求示例：

```json
{"role": "child", "announce_user_id": 2}
```

设为陌生人：

```json
{"role": "stranger"}
```

后端会校验所选成员属于该药箱家庭，并校验成员角色与 `elder/child` 一致。旧人脸升级后默认仍使用原绑定成员，不影响已有功能。
